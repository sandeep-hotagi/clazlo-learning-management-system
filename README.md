# 🎓 Clazlo Learning Management System

A modern full-stack Learning Management System (LMS) designed for schools, colleges, and educational institutions. Clazlo provides role-based access for students, teachers, parents, administrators, and organizations with secure authentication and an intuitive user interface.

---

## 🚀 Features

- 🔐 JWT Authentication
- 👨‍🎓 Student Dashboard
- 👨‍🏫 Teacher Dashboard
- 👨‍👩‍👧 Parent Portal
- 🏢 Company Dashboard
- 👨‍💼 Admin Panel
- 📅 Academic Calendar
- 📢 Announcements
- 📝 Homework Management
- 📊 Attendance Tracking
- 📚 Resource Sharing
- 📈 Reports & Analytics
- 🔔 Notifications
- 🔒 Secure Login System

## ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/sandeep-hotagi/clazlo-learning-management-system.git
```

Install dependencies

```bash
npm install
```

Start backend

```bash
cd server
npm start
```

Start frontend

```bash
cd client
npm run dev
```
